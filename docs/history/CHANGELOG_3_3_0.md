# 3.3.0 — Android + Cloud Run + Supabase

- Removed Vercel from the recommended deployment topology.
- Added native Android WebView control client.
- Added Android deployment/build documentation.
- Cloud Run remains the authoritative trading/reconciliation runtime.
- Supabase PostgreSQL is the recommended persistent database.
- Google Cloud Storage is used for persistent model artifacts.
- Paper trading, broker sandbox, and live-trading fail-closed defaults remain enabled.
