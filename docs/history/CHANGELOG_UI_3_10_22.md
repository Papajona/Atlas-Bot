# Atlas Trading UI Refresh — 3.10.22

The customer-facing web interface and Android WebView shell were redesigned to match the new Atlas Trading visual direction: deep navy surfaces, glass panels, teal/violet accents, large balance cards, structured trading workspaces, dedicated wallet/security/settings areas, and a touch-first mobile navigation bar.

Backend behavior, customer authentication, wallet funding, withdrawal security, billing, scanner, Smart Trade, DCA and strategy-builder API calls were preserved.
